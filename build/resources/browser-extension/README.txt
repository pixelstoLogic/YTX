YTX YouTube Trim Handoff — Chrome and Edge

YTX cannot silently install or enable a browser extension. To add the optional YouTube button:
1. Open chrome://extensions (Chrome) or edge://extensions (Edge).
2. Turn on Developer mode.
3. Choose Load unpacked and select this folder.

On a YouTube watch page, choose “Open in YTX”. YTX opens a preview; set the trim range and export when ready. The extension only runs on YouTube and youtu.be pages. To remove it, remove YTX YouTube Trim Handoff from the browser's Extensions page.
