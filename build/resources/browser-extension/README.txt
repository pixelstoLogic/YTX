YTX YouTube Trim Handoff — Chrome, Edge, Brave, Opera, and Vivaldi

The YTX installer registers this signed extension through the machine-wide
Chromium extension policy. Restart the selected browser once and the YouTube
button is available automatically; Developer mode and Load unpacked are not
required.

The extension is updated from the signed updates.xml published with each YTX
GitHub release. If your organization blocks browser policies, use the fallback:
open the browser's Extensions page, enable Developer mode, choose Load unpacked,
and select this folder.

On a YouTube watch page, Short, live stream, or youtu.be link, choose “Open in
YTX”. YTX opens a preview; set the trim range and export when ready. The button
follows YouTube's single-page navigation and only runs on YouTube pages.
Removing YTX through Windows Settings removes the policy and this folder.
